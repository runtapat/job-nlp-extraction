## แนวคิดของ Domain

ประกาศรับสมัครงานในเว็บไซต์หางาน/โซเชียลมีเดีย มักมีข้อมูลปะปนกันในรูปแบบข้อความอิสระ
(unstructured text) เช่น ตำแหน่งงาน ชื่อบริษัท เงินเดือน สถานที่ทำงาน ทักษะที่ต้องการ
รวมถึงข้อมูลติดต่อ เช่น เบอร์โทร อีเมล ซึ่งเป็นข้อมูลที่ไม่ต้องการนำไปวิเคราะห์ต่อ (Noise)

ระบบนี้จึงถูกออกแบบมาเพื่อ **แปลงข้อความอิสระให้เป็นข้อมูลที่มีโครงสร้าง (structured data)**
สำหรับนำไปใช้งานต่อ เช่น ทำฐานข้อมูลตำแหน่งงาน วิเคราะห์แนวโน้มตลาดแรงงาน หรือทำระบบแนะนำงาน

## เทคนิค NLP ที่นำมาประยุกต์ใช้

| ขั้นตอน | เทคนิค | รายละเอียดการใช้งานในระบบ |
|---|---|---|
| 1 | **Regex & Cleansing** | ลบเบอร์โทรศัพท์, อีเมล, ลิงก์ (URL) ออกจากข้อความก่อนประมวลผล เพื่อป้องกันข้อมูลส่วนบุคคลรั่วไหลและลด Noise |
| 2 | **Tokenization & Normalization** | ใช้ `pythainlp.tokenize.word_tokenize` (engine `newmm`) ตัดคำภาษาไทย และลบ Stopwords ด้วย `pythainlp.corpus.thai_stopwords` |
| 3 | **Topic Identification** | จัดหมวดหมู่ประเภทงาน (IT, การตลาด, งานขาย, บัญชี/การเงิน, HR, กราฟิก, บริการลูกค้า) ด้วยวิธี keyword scoring จากคำสำคัญในแต่ละหมวด |
| 4 | **POS Tagging & Rule-based NER** | ใช้ `pythainlp.tag.pos_tag` (corpus `orchid`) ติด Part-of-Speech และใช้ Regex/Keyword matching แบบ rule-based สกัด Named Entity ได้แก่ ตำแหน่งงาน, ชื่อบริษัท, เงินเดือน, สถานที่, ทักษะที่ต้องการ |

## วิธีใช้งาน

### รันบนเครื่องตัวเอง (Local)

```bash
pip install -r requirements.txt
streamlit run app.py
```

### ใช้งานผ่านหน้าเว็บ

1. เปิดแท็บ **"ทดลองข้อความเดียว"** วางข้อความประกาศรับสมัครงาน แล้วกด "ประมวลผล"
   ระบบจะแสดงผลลัพธ์การสกัดข้อมูล พร้อมรายละเอียดของแต่ละขั้นตอน (คลิกเปิดแต่ละ expander)
2. เปิดแท็บ **"ประมวลผลไฟล์ (หลายประกาศ)"** อัปโหลดไฟล์ CSV ที่มีคอลัมน์ `text`
   (สามารถใช้ `sample_data.csv` ที่แนบมาทดสอบได้) แล้วกด "ประมวลผลทั้งไฟล์"
   ระบบจะประมวลผลทุกแถวและให้ดาวน์โหลดผลลัพธ์เป็น CSV ได้

## ตัวอย่าง Prompt ที่ใช้สั่ง AI ในการพัฒนา

ตัวอย่าง prompt ที่ใช้ปรึกษา AI (Claude) ระหว่างพัฒนาโปรเจกต์นี้:

- "ช่วยออกแบบ Streamlit app สำหรับสกัดข้อมูลจากประกาศรับสมัครงานภาษาไทย/อังกฤษ
  โดยใช้ regex ลบเบอร์โทร/ลิงก์/อีเมล, ตัดคำด้วย pythainlp, จัดหมวดหมู่ประเภทงาน,
  และสกัด entity เช่น ตำแหน่งงาน บริษัท เงินเดือน สถานที่ ทักษะ"
- "ช่วยเขียนฟังก์ชัน regex สำหรับดึงช่วงเงินเดือนจากข้อความภาษาไทย เช่น
  'เงินเดือน 20,000-30,000 บาท'"
- "ช่วยสร้างไฟล์ตัวอย่างข้อมูล (sample_data.csv) ที่เป็นประกาศรับสมัครงานจำลอง
  8 รายการ มีทั้งภาษาไทยและอังกฤษ พร้อมเบอร์โทร/อีเมล/ลิงก์ปลอมสำหรับทดสอบการลบ Noise"

> **หมายเหตุ:** นักศึกษาควรปรับ/เขียน prompt ของตนเองใหม่ให้ตรงกับสิ่งที่ปรึกษา AI จริงระหว่างทำงาน

## การ Deploy ขึ้น Streamlit Community Cloud

1. สร้าง GitHub Repository (private หรือ public ก็ได้ แต่ควรตั้งเป็น public
   หรือให้สิทธิ์ผู้สอนเข้าถึงได้) แล้วอัปโหลดไฟล์ `app.py`, `requirements.txt`,
   `README.md`, `sample_data.csv` ขึ้นไป
2. ไปที่ [https://share.streamlit.io](https://share.streamlit.io) ล็อกอินด้วย GitHub
3. กด **"New app"** เลือก Repository, Branch (main) และไฟล์หลัก `app.py`
4. กด **Deploy** รอสักครู่ระบบจะสร้าง URL ให้อัตโนมัติ (รูปแบบ
   `https://<app-name>.streamlit.app`)
5. คัดลอก URL ที่ได้ไปใส่ในหัวข้อ "URL หน้าเว็บ" ด้านบนของไฟล์นี้ และในระบบส่งงาน
